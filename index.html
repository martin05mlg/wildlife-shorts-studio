Wildlife Shorts Studio

Desktop tool for local trail-camera wildlife video editing & publishing

What it does

Wildlife Shorts Studio is a Windows desktop application that processes trail-camera wildlife footage locally, detects animals to create stabilized 9:16 vertical clips, and lets the user review, approve, and upload selected videos directly to their own YouTube, TikTok, or Instagram accounts using official OAuth 2.0 APIs.

All video processing and AI tracking run locally on the user’s computer. No third-party cloud service stores user media.
